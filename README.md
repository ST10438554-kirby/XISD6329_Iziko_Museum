## Setup in Visual Studio 2022
1. Install Visual Studio 2022 with **ASP.NET and web development.
2. Install XAMPP and start **MySQL**.
3. Create the database by running `database.sql` in phpMyAdmin.
4. Open `IzikoMuseumWebsite.csproj` in Visual Studio 2022.
5. Check the connection string in `appsettings.json`:
   `server=localhost;port=3306;database=iziko_museum;user=root;password=;`
6. Build and run the project.
7. Seeded administrator account:
   Username: `admin`
   Password: `Admin@123`
